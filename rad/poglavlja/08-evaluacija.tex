% Budžet: ~2,5 str. OVO ODGOVARA RQ2.
%
% RETCI: svih 12 načina otkazivanja iz 6.2 — A1, A2, B1--B4, C1--C3,
%   D1, D2, E1. NE skupljati po skupinama A--E: B2 i B4 su u istoj
%   skupini a ponašaju se posve različito, i to bi se izgubilo.
%
% STUPCI: šest obrazaca —
%   istek vremena · ponavljanje svjesno roka · odlazni pretinac i zapis
%   namjere · automat s imenovanim stanjem · ključ za deduplikaciju · prekidač
%   Prekidač je unutra da bi se vidjelo "pogoršava".
%   KOMPENZACIJA NEMA STUPAC — nema predmet ni u jednom retku (v. 5.2 i
%   6.3). To se kaže jednom rečenicom, ne praznim stupcem.
%
% ★ PRAZNA ĆELIJA JE NALAZ. Redak u kojem je pola stupaca prazno pokazuje
%   RUPU, a rupa je poanta rada. Zato punih 12 redaka.
%
% U PROZI se razrađuje ~10 ćelija, ne svih 72:
%   - sve ćelije "pogoršava"
%   - B2 x zapis namjere  → ovo je ćelija tipa (b), dokazuje je pogl. 7
%   - B1 x automat        → imenovanje stanja koje propis ne imenuje
%   - C1 i C3 retci       → gotovo prazni, i to je odgovor
%
% POZNATE ĆELIJE KOJE VEĆ IMAJU PRESUDU (iz 6.3):
%   prekidač x D1  = POGORŠAVA, razina (c) — rok teče dok je otvoren
%   prekidač x D2  = sužava, razina (c) — druga granica, ondje ima smisla
%     ⚠ te dvije ćelije zajedno pokazuju da presuda ovisi o GRANICI,
%       ne o obrascu. To je precizniji nalaz od ravnog odbacivanja.
%   B3: ponavljanje cijele skupne poruke = pogoršava (rizik duplikata).
%     Praktičan izlaz je ODUSTATI OD SKUPNOSTI, jer kardinalnost [1,100]
%     dopušta i jedan zapis po poruci. Napisati to — mitigacija je
%     odricanje od značajke sučelja.
%
% TABLICA: booktabs, landscape ako ne stane. Kratice u zaglavlju uz
%   legendu ispod. Razina (a)/(b)/(c) kao indeks uz vrijednost ćelije.
